# Testimonios

Agrega un archivo JSON por testimonio dentro de `es/` (y `en/` cuando exista la versión en inglés).
La sección de testimonios aparece en el home automáticamente cuando hay al menos uno.

```json
{
  "order": 1,
  "quote": "Texto del testimonio, en primera persona y con un resultado concreto.",
  "name": "Nombre Apellido",
  "role": "Cargo",
  "company": "Empresa"
}
```
